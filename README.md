# Data Structures & Algorithms (DSA)

A comprehensive collection of Data Structures and Algorithms implementations, pattern printing exercises, and problem-solving solutions.

## 📁 Repository Structure

```
DSA/
├── Pattern Printing/          # Pattern printing exercises
│   └── Pattern 1.py          # Various star/number pattern implementations
├── .gitignore                # Git ignore rules
└── README.md                 # This file
```

## 🚀 Topics Covered

- **Pattern Printing** - Star patterns, number patterns, pyramid patterns
- **Data Structures** - Arrays, Linked Lists, Stacks, Queues, Trees, Graphs, Hash Tables
- **Algorithms** - Sorting, Searching, Dynamic Programming, Greedy, Backtracking
- **Problem Solving** - LeetCode, Codeforces, GeeksforGeeks solutions
